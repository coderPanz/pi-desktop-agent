# ctx 的作用

`ctx` 是传给 PI-Durable 与 Chord API 的 `Context`。它携带当前调用链的取消信号、遥测信息和上下文值。

阶段 1 使用：

```ts
import { BACKGROUND_CONTEXT } from "@earendil-works/chord/context";

const ctx = BACKGROUND_CONTEXT;
```

`BACKGROUND_CONTEXT` 是没有取消信号的后台根上下文，适合脚本中需要完成的调用链。

## 取消语义

从 `withCancel(ctx)` 得到的子 context 被取消后，使用该 context 等待的 API 可以提前结束或抛出取消错误。

```ts
const { context, cancel } = withCancel(BACKGROUND_CONTEXT);
const waiting = submission.wait(context);
cancel();
```

这只取消等待，不会撤回已经提交且开始运行的会话任务。要停止会话正在运行的普通任务，应调用：

```ts
await conversation.abort(ctx);
```

因此，`ctx` 用于传播调用取消；`conversation.abort()` 用于请求停止会话工作。
