# 什么是 ops

`ops` 是 Chord 的**操作批**（operations）：一组 JSON 元组，描述状态如何从旧值变成新值。

```ts
import type { Op } from "@earendil-works/chord/delta";
```

订阅回调的第二个参数就是它：

```ts
watch.start(async (value, ops) => {
  // ops：从上一版状态变到 value 所需的一组操作。
});
```

`value` 告诉你结果是什么，`ops` 告诉你怎么得到这个结果。跨进程同步只用传 `ops`，不必每次重发完整状态。

## 类型

```ts
type Op =
  | readonly ["r", JsonValue]
  | readonly ["s", NonEmptyPath, JsonValue]
  | readonly ["d", NonEmptyPath]
  | readonly ["a", NonEmptyPath, string]
  | readonly ["t", NonEmptyPath, number]
  | readonly ["p", Path, number, number, JsonValue[]]
  | readonly ["m", Path, number[]];
```

每个操作由「动词 + 路径 + 载荷」组成。路径段只能是 `string` 或 `number`。

## 具体结构

### 逐位拆解

```ts
// 一帧的完整载荷：一个操作数组。
type Ops = readonly Op[];

// 路径 = 段数组；段只能是对象键（string）或数组下标（number）。
type Seg = string | number;
type Path = readonly Seg[];
type NonEmptyPath = readonly [Seg, ...Seg[]]; // s/d/a/t 不允许空路径

// [0] 是动词，后面几位固定含义。
type Op =
  | readonly ["r", JsonValue]                         // [0]="r" [1]=新的根值
  | readonly ["s", NonEmptyPath, JsonValue]           // [0]="s" [1]=路径 [2]=新值
  | readonly ["d", NonEmptyPath]                      // [0]="d" [1]=路径
  | readonly ["a", NonEmptyPath, string]              // [0]="a" [1]=路径 [2]=追加的文本
  | readonly ["t", NonEmptyPath, number]              // [0]="t" [1]=路径 [2]=要丢弃的前缀字符数
  | readonly ["p", Path, number, number, JsonValue[]] // [0]="p" [1]=数组路径 [2]=start [3]=deleteCount [4]=插入项
  | readonly ["m", Path, number[]];                   // [0]="m" [1]=数组路径 [2]=置换表
```

路径里每一段的含义就两种：

```ts
["docs", "pi.live", "generation", "message", "content", 0, "text"]
//  ↑对象键    ↑对象键      ↑对象键        ↑对象键    ↑数组    ↑下标  ↑对象键
// 等价于：view.docs["pi.live"].generation.message.content[0].text
```

### 一帧的真实组合

一帧里通常既有文档操作、也有条目操作。下面这批 `ops` 已实测应用成功：

```ts
const ops: readonly Op[] = [
  // 1. 追加流式回答：路径 ...content[0].text
  ["a", ["docs", "pi.live", "generation", "message", "content", 0, "text"], "，世界"],

  // 2. 新的条目写入转录：在 entries 末尾开始位置插入
  ["p", ["entries"], 2, 0, [{ id: 11, conversationId: 1, kind: "pi.assistant", model: [] }]],

  // 3. 文档内部某个字段变化：直接 set
  ["s", ["docs", "pi.live", "generation", "attempt"], 2],
];
```

应用后（`entries` 从 2 条变 3 条、文本变为「你好，世界」、attempt 变为 2），旧副本保持不变。

文档整体出现或消失时，操作都落在 `docs.<kind>` 这一层：

```ts
// 文档首次出现或版本变化：整份 set
applyImmutable({ entries: [], docs: {} }, [
  ["s", ["docs", "pi.live"], { run: { taskId: 9, inputs: [8] } }],
]);
// { entries: [], docs: { "pi.live": { run: { taskId: 9, inputs: [8] } } } }

// 文档被删除（例如 run 结束）
applyImmutable({ entries: [], docs: { "pi.live": { run: 1 } } }, [
  ["d", ["docs", "pi.live"]],
]);
// { entries: [], docs: {} }
```

注意：操作是**依次**应用的。若前一条把某路径整份替换成不含该字段的结构，后一条指向该字段的操作就会抛 `PathError`。

## 七个操作

| 动词 | 形状 | 语义 |
|---|---|---|
| `r` | `["r", value]` | 替换整个根值。唯一能作用于根的操作，其余动词不能以空路径为目标。 |
| `s` | `["s", path, value]` | 把 `path` 处的值设为 `value`。 |
| `d` | `["d", path]` | 删除 `path`。父容器是数组时执行 `splice(index, 1)`，是对象时执行 `delete`。 |
| `a` | `["a", path, text]` | 向字符串尾部追加 `text`；当前值必须是字符串，否则抛错。 |
| `t` | `["t", path, count]` | **去掉字符串开头的 `count` 个字符**（`current.slice(count)`）；当前值必须是字符串。 |
| `p` | `["p", path, start, deleteCount, items]` | 数组拼接：先 `splice(start, deleteCount)`，再在该位置插入 `items`。`deleteCount` 为 0 即纯插入。 |
| `m` | `["m", path, permutation]` | 数组重排：`new[i] = old[permutation[i]]`。必须是双射，且长度与被重排数组一致。 |

`a` 与 `t` 通常成对出现：`t` 去掉已经相同的公共前缀，`a` 追加新的后缀，避免整段字符串重传。这与 `diff.js` 的生成方式一致。

## 路径校验

应用时对每个操作做校验（`assertValidOp`）：

- `s` / `d` / `a` / `t` 的路径必须非空。
- 父容器是数组时，`path` 最后一段必须是合法的数字下标。
- 路径段命中 `__proto__` / `constructor` / `prototype` 时抛 `UnsafePathError`，防止原型污染。
- 动词或元数不合法时抛 `TypeError`，不会静默跳过。

`ops` 来自远端或工具输出，均属不可信数据，因此校验不是可选项。

## 顺序与批次

- 一批 `ops` 按数组顺序依次应用，后一个操作看到的是前一个操作的结果。
- `r` 只会出现在位置 0 或不存在，因此可用 `isBase(ops)` 精确判断整帧。
- 应用不修改输入状态：`applyImmutable(prev, ops)` 返回新值并复用未改动的子树（结构共享）。

整帧与增量帧的区别见 [5. 整帧与增量帧.md](./5.%20%E6%95%B4%E5%B8%A7%E4%B8%8E%E5%A2%9E%E9%87%8F%E5%B8%A7.md)。

## 示例

以下结果均为实际运行 `applyImmutable` 得到的输出。

### `r`：替换根

```ts
applyImmutable({ a: 1 }, [["r", { a: 2, b: 3 }]]);
// { a: 2, b: 3 }
// isBase(ops) === true
```

旧值不被修改，直接以新值作为根。

### `s`：设置路径

```ts
applyImmutable({ a: 1, b: 2 }, [["s", ["a"], 9]]);
// { a: 9, b: 2 }
```

嵌套路径同理，这也是 `pi.live` 文本改写的常见形式：

```ts
const path = ["docs", "pi.live", "generation", "message", "content", 0, "text"];
applyImmutable(view, [["s", path, "你好呀"]]);
// 该路径下的 "你好" 被替换为 "你好呀"
```

### `d`：删除

对象：

```ts
applyImmutable({ a: 1, b: 2 }, [["d", ["b"]]]);
// { a: 1 }
```

数组（按下标删除一个元素，后续元素前移）：

```ts
applyImmutable({ list: ["x", "y", "z"] }, [["d", ["list", 1]]]);
// { list: ["x", "z"] }
```

### `a`：向字符串尾部追加

```ts
applyImmutable({ text: "你好" }, [["a", ["text"], "，世界"]]);
// { text: "你好，世界" }
```

当前值不是字符串时抛错，不能用 `a` 初始化一个字符串。

### `t`：去掉字符串开头的 N 个字符

```ts
applyImmutable({ text: "你好世界" }, [["t", ["text"], 2]]);
// { text: "世界" }
```

注意不是「保留前 N 个」也不是「截到长度 N」。它常与 `a` 配对，用于边改边追加：

```ts
applyImmutable({ text: "ABCDEFGH" }, [
  ["t", ["text"], 4],
  ["a", ["text"], "efgh!"],
]);
// { text: "EFGHefgh!" }
```

### `p`：数组拼接

`p` 先执行 `splice(start, deleteCount)`，再在该位置插入 `items`。

纯插入（`deleteCount` 为 0）：

```ts
applyImmutable({ list: ["a", "c"] }, [["p", ["list"], 1, 0, ["b"]]]);
// { list: ["a", "b", "c"] }
```

删除：

```ts
applyImmutable({ list: ["a", "b", "c"] }, [["p", ["list"], 1, 1, []]]);
// { list: ["a", "c"] }
```

替换为一个或多个元素：

```ts
applyImmutable({ list: ["a", "b", "c"] }, [["p", ["list"], 1, 1, ["B", "B2"]]]);
// { list: ["a", "B", "B2", "c"] }
```

### `m`：数组重排

```ts
applyImmutable({ list: ["a", "b", "c"] }, [["m", ["list"], [2, 0, 1]]]);
// { list: ["c", "a", "b"] }
```

`permutation` 的语义是 `new[i] = old[permutation[i]]`，必须是双射且长度与原数组一致。

## 这些操作从哪里来

大多数 `ops` 不需要手写，由 `diffRevisions(before, after)` 生成：

```ts
// 文本变长 → 只用 a
["a", ["docs", "pi.live", "generation", "message", "content", 0, "text"], "，世界"]

// 文本改写 → 整体 set
["s", ["docs", "pi.live", "generation", "message", "content", 0, "text"], "ABCDwxyz"]

// 数组末尾新增一条 → 纯插入 p
["p", ["entries"], 2, 0, [3]]
```

## 非法操作示例

| 操作 | 结果 |
|---|---|
| `["s", [], 2]` | `TypeError: path is empty`（`s` 不能作用于根） |
| `["s", ["__proto__", "isAdmin"], true]` | `UnsafePathError: unsafe path segment: __proto__` |
| `["a", ["n"], "x"]`（`n` 是数字） | `PathError: unresolvable path: ["n"]` |
| `["d", ["list", 5]]`（数组无下标 5） | `UnsafePathError: unsafe path segment: 5` |
| `["m", ["list"], [0, 0, 1]]` | `TypeError: m permutation is not a bijection` |
| `["x", ["a"], 1]` | `TypeError: unknown op verb: x` |
