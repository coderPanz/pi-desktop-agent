# useCallback
定义：缓存函数本身，避免每次渲染时都重新创建新的函数。
**useCallback 的本质目标只有一个：稳定函数引用**。
## 痛点
React 组件每次重新渲染，组件内部所有函数都会**重新创建一份全新的函数**：
```tsx
function Demo() {
  const [count, setCount] = useState(0)
  // ❌ 每次渲染，onClick 都是新函数
  const onClick = () => {
    setCount(c => c + 1)
  }
  return <Child onClick={onClick} />
}
```
只要 `Demo` 重新渲染，`onClick` 被销毁并重新创建，引用就变了。
如果 `Child` 包了 `React.memo`（浅比较 props），**props.onClick 一变，Child 就会不必要重渲染**。
👉 这就是 useCallback 的典型场景：**传给被 memo 包裹的子组件的回调函数**。

## React.memo
`React.memo` 只是做 **props 的浅比较**。
父组件渲染后，只要这次传给子组件的 **props 和上一轮 props 浅比较结果不一样，子组件照样重渲染**。

什么是浅比较？  
- 基本类型：`number / string / boolean / null / undefined` → 直接比值
- 引用类型：`object / array / function` → **只比较内存地址（引用），不深度对比里面内容**

把子组件用 `React.memo` 包裹，父组件通过 `useCallback` 缓存回调函数；**当 useCallback 的依赖不变时**，父组件重新渲染，这个函数的引用保持不变。如果子组件收到的所有 props（包括这个回调、其他 props）浅对比全部相等，子组件才会跳过重渲染。
