# 自定义hook
自定义 Hook 就是以 `use` 开头的普通函数，用来封装一组相关的状态 + 副作用逻辑，实现状态逻辑复用。UI 的复用叫 React 组件

把 `useState / useEffect / useRef` 这些内置 Hook 打包封装。

## 设计的目的
1. **抽离和复用带状态、副作用的逻辑**
组件复用分两种：
- 复用 UI：抽成组件（比如 Button、Modal）
- 复用**带状态的逻辑**：自定义 Hook（鼠标位置、请求、本地存储、订阅、防抖）

2. **关注点分离，让组件代码干净**
组件里只关心渲染；把 “怎么拿数据、怎么监听、怎么清理” 的逻辑挪到 hook 里，组件只取返回值渲染。

## 设计思想
纯函数

## 规则
- 名字必须以 `use` 开头（React 靠这个识别它是 Hook，检查 Hook 规则）
- 只能在**函数组件或者别的自定义 Hook**里面调用
- 内部依然遵守 Hook 规则：只能顶层调用，不能放在 if /for/ 回调里


## 副作用是什么
函数式里：**纯函数只依赖输入，不修改外部任何东西，也不读取外部可变东西**。
只要函数做了「超出根据 props/state 算 JSX」之外的事情，就叫副作用。

常见副作用（自定义 Hook 经常封装的）
1. 发网络请求（fetch /axios）
2. 订阅事件：window.resize、scroll、socket、定时器
3. 手动操作 DOM：获取 dom 宽高、focus input
4. 读写 localStorage /sessionStorage
5. 定时器 setInterval、setTimeout
6. 事件监听、第三方实例挂载（图表、富文本编辑器）

✅ 为什么叫副作用：
组件渲染（return JSX）是**主作用**；上面这些是顺带产生的、会影响外部环境的操作。

## 拓展
React 组件函数理想上是**纯函数**：输入 props，输出 JSX
```tsx
// 纯的：同样 props，渲染结果永远一样，不影响外面
function Hello({name}) {
  return <div>hi {name}</div>
}
```

很多组件需要**记住自己的数据**：输入框的值、开关是否打开、列表加载到第几页、loading 标记。
这份**保存在 React 内部、修改它会触发组件重渲染的数据，就是 useState 维护的状态**。
