# PI-Durable 里的帧是什么
帧是一次订阅回调收到的状态更新批次。它不是视频帧，也不等于一个模型 token 或一个字符。

```ts
watch.start(async (value, ops) => {
  // 此回调的一次执行就是一帧。
});
```

| 数据 | 含义 |
|---|---|
| `value` | 应用本帧后得到的完整 `ConversationView`。 |
| `ops` | 从上一帧状态变为 `value` 所需的一组 Chord 操作。 |

帧通常由一次已提交的状态变化产生。例如，开始运行、写入实时回答、追加文本、将回答写为正式 assistant entry，都会形成新的帧。

## 两种帧

- **增量帧**：`ops` 只描述变化，必须基于上一版副本应用。
- **整帧**：`ops` 以根替换操作 `['r', value]` 开头，表示完整状态，应覆盖旧副本。

使用 `isBase(ops)` 区分整帧：

```ts
const next = isBase(ops)
  ? applyImmutable(undefined, ops)
  : applyImmutable(previous, ops);
```

`ops.length` 表示本帧包含的操作数量，不表示文本字符数量。默认生成进度按约 100ms 间隔提交，因此一段回答通常会跨多个帧出现。

副本的定义和处理边界见 [1. 什么是 replica.md](./1.%20%E4%BB%80%E4%B9%88%E6%98%AF%20replica.md)。
