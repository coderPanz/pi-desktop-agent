# 整帧与增量帧

订阅回调收到的每一帧，其 `ops` 只有两种形态：**增量帧**或**整帧**。

## 如何区分

```ts
export const isBase = (ops) => ops.length > 0 && ops[0][0] === "r";
```

- `isBase(ops) === false`：增量帧。
- `isBase(ops) === true`：整帧。

判断依据只有一条：`ops` 的第一个操作是不是根替换 `["r", value]`。不要用「`ops` 里有没有 `r`」或「`ops.length === 1`」来判断。

## 增量帧

增量帧只描述「哪里变了」，必须基于上一版副本应用。

```ts
applyImmutable(previous, ops);
```

常见操作形式：

| 操作 | 形状 | 作用 |
|---|---|---|
| `s` | `["s", path, value]` | 设置某个路径的值 |
| `d` | `["d", path]` | 删除某个路径 |
| `a` | `["a", path, text]` | 向字符串尾部追加文本 |
| `t` | `["t", path, length]` | 截断字符串 |
| `p` | `["p", path, start, deleteCount, items]` | 修改数组 |
| `m` | `["m", path, permutation]` | 重排数组 |

### 增量帧示例

当前副本：

```ts
const previous: Replica = {
  entries: [],
  docs: {
    "pi.live": {
      generation: {
        message: {
          content: [{ type: "text", text: "你好" }],
        },
      },
    },
  },
} as Replica;
```

此时收到一个增量帧：

```ts
const ops: Op[] = [
  [
    "a",//  向字符串尾部追加文本
    // 路径：replica.docs["pi.live"].generation.message.content[0].text 追加 "，世界"
    ["docs", "pi.live", "generation", "message", "content", 0, "text"],
    "，世界",
  ],
];
```

`applyImmutable(previous, ops)` 的结果：

```ts
const result: Replica = {
  entries: [],
  docs: {
    "pi.live": {
      generation: {
        message: {
          content: [{ type: "text", text: "你好，世界" }],
        },
      },
    },
  },
} as Replica;
```

`previous` 本身不被修改；未受影响的子树（如 `entries`）在新结果中被复用。

## 整帧

整帧是「完整状态」，应覆盖旧副本，不参与合并。

```ts
applyImmutable(undefined, ops);
```

第一个操作必须是 `["r", value]`，表示替换根：

```ts
const ops: Op[] = [["r", fullConversationView]];
```

整帧不会携带上一版的状态信息，因此传入 `undefined` 而不是 `previous`。

### 整帧的来源

已核实的两种来源（`pi-durable/dist/session/observation.js`）：

1. **积压折叠**：待投递帧达到 `MAX_PENDING_WATCH_FRAMES = 100` 时，队列被清空，改为投递单帧 `[["r", 最新完整视图]]`。客户端会看到同步序号跳号。
2. **视图退役**：`RETIREMENT_OPERATIONS = [["r", null]]`，表示该视图已退役。

注意：文档内部的整体替换**不是**整帧。视图发布时，文档的根替换会被改写成 `["s", ["docs", kind], value]`（`view.js` 的 `prefixed`），仍然是增量帧。

## 对比

| 方面 | 增量帧 | 整帧 |
|---|---|---|
| 首操作 | `s` / `d` / `a` / `t` / `p` / `m` | `["r", value]` |
| 判断 | `isBase(ops) === false` | `isBase(ops) === true` |
| 应用基准 | 上一版副本 `previous` | `undefined` |
| 语义 | 在旧副本上打补丁 | 完整覆盖 |
| 典型时机 | 每次普通提交 | 积压折叠、视图退役、重新同步 |

## 用错会怎样

| 错误 | 后果 |
|---|---|
| 把整帧当增量应用 | 旧消息残留、文本回退或重复；整帧的根替换会覆盖，但若先合并旧值仍可能产生偏差 |
| 把增量当整帧应用 | `applyImmutable(undefined, 非 r 操作)` 非法，抛错 |

统一写法：

```ts
export function applyFrame(prev: Replica | undefined, ops: readonly Op[]): Replica | undefined {
  if (ops.length === 0) return prev;
  return isBase(ops)
    ? applyImmutable<Replica>(undefined, ops)
    : applyImmutable(prev, ops);
}
```
